# Tone calibration

## The formality ladder

| Level | Use for | Greeting | Close | Marker |
| ----- | ------- | -------- | ----- | ------ |
| 1 Formal | Government, legal, first contact with senior external, Gulf institutions | `Dear Mr./Ms. <Surname>,` | `Kind regards,` | No contractions, full titles, no humor |
| 2 Professional | Most external business, cross-company | `Dear <First>,` / `Hi <First>,` | `Best regards,` | Contractions fine, no slang |
| 3 Neutral-direct | Internal peers, ongoing threads | `Hi <First>,` | `Best,` / `Thanks,` | Default for most work email |
| 4 Warm-direct | Close colleagues, long relationships | `Hi <First>,` / none | `Cheers,` / first initial | Fragments OK, light humor |
| 5 Casual | Team chat spillover into email | none | initial only | Anything goes, still no typos |

Default to **3** unless `MEMORY.md` says otherwise or the thread says otherwise.

## Mirroring rule

In a reply, match the sender's level — or go **one notch warmer, never two, and
never cooler**. Going cooler reads as a rebuke; going two warmer reads as
presumptuous.

Mirror specifically: greeting form, sign-off length, contraction use,
paragraph length, and whether they use bullets.

## Seniority adjustment

- **Upward (exec, client, regulator):** shorter, decision-first, no process
  detail, explicit ask, no jargon. Assume they read on a phone, in 8 seconds.
- **Lateral:** context is welcome, collaborative framing, options rather than
  directives.
- **Downward:** be explicit about the *why* and the deadline; ambiguity from a
  senior person reads as a test. Never soften a deadline into a suggestion.

## Emotional register

| You feel | Write at | Because |
| -------- | -------- | ------- |
| Angry | one notch cooler, half the length | Heat is legible and permanent |
| Anxious | direct, no hedging | Hedging signals the weakness you're hiding |
| Apologetic | brief, fix-forward | Long apologies center you, not them |
| Excited | one notch cooler | Enthusiasm survives compression; hype doesn't |

Hedges to cut: *just, actually, sort of, I think maybe, quick, sorry to bother,
if that's okay, no worries if not* (except as a deliberate easy-out in a
follow-up), *I could be wrong but.*

## Gulf / UAE & international conventions

The user is based in Sharjah, UAE — assume a mixed international audience.

- **Working week:** Mon–Fri in the UAE (Sat–Sun weekend). Many regional
  counterparts still run Sun–Thu. Never assume Friday is a working day for
  Gulf government or a Sunday is a weekend for Saudi/Kuwait partners.
- **Times:** always state the timezone — `14:00 GST (GMT+4)`. Use 24h with
  European/Gulf recipients, 12h with US recipients.
- **Dates:** write `12 Mar 2026`, never `03/12/2026` — the ambiguity bites.
- **Titles matter** in Gulf formal correspondence: `H.E.`, `Dr.`, `Eng.`,
  `Sheikh`. Carry over exactly what the recipient used in their own signature.
- **Ramadan / Eid / National Day:** shift deadlines, don't chase during, and
  a one-line greeting at the start of the period is normal and welcome.
- **Arabic:** if the thread or the recipient's signature is Arabic, ask whether
  to draft in Arabic; if yes, draft in Modern Standard Arabic at formality
  level 1–2, with the English version below for the user's own check.
- **Non-native English readers:** shorter sentences, no idioms
  ("ballpark", "touch base", "circle the wagons"), no phrasal-verb stacks.

## Warmth without filler

Warmth comes from **specificity and generosity**, not adjectives.

- Cold: `Thanks for your help.`
- Warm: `Thanks for turning the redlines around on a Thursday night.`
- Cold: `Let me know if you need anything.`
- Warm: `If it's faster, send me the raw file and I'll clean it up.`

## Sensitive-topic register

Legal, HR, compensation, safety, termination, refunds: drop to level 2,
state facts only, never characterize intent, never joke, never use emoji, and
assume the email will be read aloud in a meeting you're not in.
