# Pre-send checklist

Run this on every draft before output. Silent pass — only surface failures.

## The ask
- [ ] There is exactly **one** ask, and it's in the first two sentences.
- [ ] The recipient can act without opening an attachment or asking a question.
- [ ] There's a deadline, or an explicit "no rush".
- [ ] Next step names an owner and a date.

## Truth
- [ ] Zero invented facts: no unverified dates, numbers, names, prices, links.
- [ ] Every unknown is a visible `[TODO: ...]`, not a plausible guess.
- [ ] No commitment made that falls under MEMORY.md guardrails.
- [ ] Any attachment mentioned actually exists / was provided.

## Voice
- [ ] Matches the formality level in `tone.md` for this recipient.
- [ ] Greeting and sign-off are exactly the user's, from MEMORY.md.
- [ ] No banned words from MEMORY.md.
- [ ] No AI tells: *hope this finds you well · wanted to reach out · circling
      back · per my last email · delve · leverage · seamless · don't hesitate.*
- [ ] Reads as the user, not about the user.

## Craft
- [ ] Subject is 6–9 words, specific, front-loaded.
- [ ] No sentence over 25 words.
- [ ] No paragraph over 4 lines.
- [ ] Hedges cut: *just, actually, sort of, I think maybe, sorry to bother.*
- [ ] Closing paragraph doesn't restate the email.
- [ ] Within the length target for this email type.

## Safety
- [ ] Legal / HR / financial / safety content carries the `⚠` flag.
- [ ] Nothing that would embarrass the user if forwarded or screenshotted.
- [ ] No third party characterized negatively by name.
- [ ] Reply-all is correct — flag if the draft is going wider than it should.
- [ ] Recipients, CC, and BCC are stated and deliberate.

## Output
- [ ] `Subject:` line present.
- [ ] Two alternate subject lines offered.
- [ ] `Assumed:` line lists every inference made.
- [ ] `Learned:` line present if MEMORY.md was updated.

## Memory
- [ ] No question asked that MEMORY.md already answers.
- [ ] Any new recipient added to the `## Recipients` table.
- [ ] Any new stated preference written to the learning log with a date.
